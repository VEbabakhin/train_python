Знакомство с Python. Команды print() и input()

1Что такое Python

Python — это язык программирования. Программа на Python — это набор инструкций, которые компьютер выполняет по очереди, сверху вниз.

В этом уроке мы разберём две самые важные команды: print() (вывести на экран) и input() (получить данные от пользователя).

2Функция print()

print() выводит данные на экран. Всё, что написано в кавычках внутри скобок, будет напечатано. Кавычки при выводе не показываются.

Строки в Python можно заключать как в двойные кавычки "…", так и в одинарные '…' — результат одинаковый.

Каждый вызов print() печатает текст с новой строки. Программа с двумя вызовами выведет две строки:

— вывод появится здесь —

Можно передать сразу несколько значений через запятую — они выведутся через пробел:

— вывод появится здесь —

Между "Меня зовут" и "Иван" print сам добавляет один пробел. Именно так удобно собирать фразы из нескольких частей.

3Функция input()

input() читает одну строку, которую вводит пользователь, и возвращает её как текст. Обычно результат сохраняют в переменную, чтобы потом использовать.

Переменная — это имя, под которым хранится значение. Знак = в Python — это «присвоить», а не «равно».

В поле ниже введи своё имя и нажми «Запустить».

Что происходит построчно:

  1. name = input() — ждём ввода и сохраняем его в переменную name.
  2. print("Привет,", name) — выводим приветствие. Значения через запятую печатаются через пробел.

Аргумент внутри input("...") — это подсказка, которую видит пользователь. В задачах курса подсказку обычно не пишут — она не должна попадать в вывод программы.
