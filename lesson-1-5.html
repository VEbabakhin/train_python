Целочисленная арифметика, часть 2

1Зачем ещё два оператора

В уроке 1.4 мы научились складывать, вычитать, умножать и возводить в степень. Но есть задачи, где нужно понять, сколько целых раз одно число помещается в другое, и сколько остаётся. Для этого в Python есть два оператора: // и %.

2Деление нацело: //

Оператор // отвечает на вопрос: сколько целых раз правое число помещается в левое. Дробную часть он отбрасывает.

Сколько полных пятёрок помещается в 17?

— вывод появится здесь —

17 = 5 + 5 + 5 + 2. Полных пятёрок три, остаток 2. Ответ — 3.

3Остаток от деления: %

Оператор % отвечает на вопрос: сколько останется после того, как мы заберём все полные части.

— вывод появится здесь —

После трёх полных пятёрок остаётся 2. Ответ — 2.

4Как связаны // и %

Операции дополняют друг друга. Если a // b — это «сколько полных частей», а a % b — «сколько осталось», то вместе они полностью разбирают число a на части по b.

— вывод появится здесь —

20 = 6 × 3 + 2. Шесть полных троек и остаток 2 — всё сходится.

5Приоритет

// и % имеют такой же приоритет, как умножение *. То есть они выполняются раньше сложения и вычитания.

— вывод появится здесь —

Сначала 10 % 3 = 1, потом 7 + 1 = 8.

6Отрицательные числа

В Python // и % работают и с отрицательными числами, но результат может удивить. Правила такие:

  • // всегда округляет результат вниз (к минус бесконечности), а не «к нулю».
  • % всегда возвращает остаток того же знака, что у делителя (правого числа).
— вывод появится здесь —

−7 // 2 = −4, а не −3, потому что −3.5 округляется вниз до −4. −7 % 2 = 1, потому что −7 = 2 × (−4) + 1.

Связь между операциями работает и здесь: всегда верно, что (a // b) * b + (a % b) = a. Проверим на тех же числах: (−4) * 2 + 1 = −8 + 1 = −7 — вернулись к исходному числу.
